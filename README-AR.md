# 대전전투 AR 시험판

벽에 걸린 대형 사진에 폰 카메라를 비추면 사진 위에 지명 표식(점과 이름표)이 붙고, 누르면 카드가 열립니다.

## 올리는 법
이 폴더 전체(`ar.html`, `vendor/`, `targets/`)를 GitHub 저장소의 `index.html` 옆에 그대로 올립니다.
접속 주소는 `https://jeongsi86.github.io/DaejeonSky/ar.html` 입니다. (카메라는 https에서만 켜집니다.)

## 지금 시험해 보는 법
1. 올린 뒤 컴퓨터 화면에 `targets/battle-main.jpg`(전시 사진 축소본)를 크게 띄웁니다.
2. 휴대폰으로 `ar.html` 을 열고 [카메라 켜기]를 누른 뒤 컴퓨터 화면을 비춥니다.
3. 번호 표식이 사진 위에 붙으면 성공입니다. 표식을 눌러 설명 카드를 확인합니다.

## 가까이서도 인식되게 한 방법 (대형 사진용)
- 사진 전체 1개와, 서로 겹치는 조각 8개(가로 4 × 세로 2)를 한 파일(`targets/battle-tiles.mind`, 약 10MB)에 넣었습니다. 가까이 가면 보이는 조각이, 멀리서는 전체 사진이 인식됩니다. 핀 좌표는 어느 쪽으로 인식되든 같은 값(사진 전체 기준 비율)을 씁니다.
- 인식 엔진의 추적 해상도 설정을 올렸습니다(`vendor/controller-…js` 안의 `Y5 = 0`). 이 파일을 공식 버전으로 바꾸면 이 개선이 사라집니다.
- 핀 위치에 떨림 완화 필터를 넣었습니다. 주소 뒤에 `?mc=0.5&beta=0.02` 처럼 붙여 현장에서 바로 조절할 수 있습니다. `mc`를 낮추면 더 안정적이고 조금 늦게 따라오며, `beta`를 높이면 움직일 때 덜 늦습니다. 기본값은 `mc=0.7`, `beta=0.03` 입니다.
- 폰이 느려서 끊기면 `?hq=1` 없이(기본) 쓰고, 정밀도를 더 올리고 싶으면 `?hq=1`(카메라 1280×720)을 붙여 비교해 보세요.
- 사진을 바꾸면 조각도 다시 만들어야 합니다. 저에게 새 사진을 주세요.

## 지점 핀 고치는 법
현재 핀 26개는 주석 사진의 노란 글씨(지명) 위치를 사진에 맞춰 옮긴 것이며, 이름만 있고 설명은 아직 없습니다. 빨간 글씨(철도·군사 시설) 지점은 뺐습니다. 이름표가 겹치면 목록 앞쪽 항목이 먼저 보이고, 가까이 갈수록 더 많은 이름이 나타납니다.
1. `ar.html?edit=1` 로 열어 사진을 비추고 원하는 지점을 탭하면 `x: 0.378  y: 0.317` 같은 좌표가 표시됩니다.
2. `ar.html` 위쪽 설정 영역의 `PINS` 목록에서 좌표, 제목, 설명을 바꾸거나 항목을 추가합니다. 설명을 넣으려면 `{ x:0.5, y:0.3, title:'이름', text:'설명' }` 처럼 `text:` 를 붙이면 됩니다.

## 다른 사진으로 바꾸는 법
사진을 MindAR 공식 변환 도구(hiukim.github.io/mind-ar-js-doc/tools/compile)에서 `.mind` 파일로 변환해 `targets/` 에 넣고, 설정 영역의 `TARGET` 경로를 바꿉니다. 저에게 사진을 주시면 제가 변환해 드립니다.

## 도슨트 페이지(대전전투 구역)에 넣을 버튼
```html
<a class="btn" href="./ar.html">대형 사진에 비춰 보기 (AR)</a>
```
(`.btn` 대신 기존 버튼 스타일을 쓰셔도 됩니다.)

## 현장 점검
- 사진은 무광으로 출력하고, 유리나 아크릴을 씌우면 반사 때문에 인식이 떨어집니다.
- 사진 앞 조명이 너무 어둡지 않은지 확인합니다.
- 설치 후 아이폰과 안드로이드 각각으로 인식되는 거리와 각도를 시험합니다.
- AR이 안 되는 폰을 위해 도슨트 글 페이지는 그대로 기본 경로로 둡니다.
